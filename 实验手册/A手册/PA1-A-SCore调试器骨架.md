## 这一阶段你要做什么

你要在 SCore 里实现一个交互式调试器（SDB），它的体验类似于你可能用过的 `gdb`：启动后出现提示符，等你输入命令，然后执行对应操作。

本阶段你负责的命令：`si`（单步执行）、`info r`（查看寄存器）、`x`（查看内存）、`help`、`q`（退出）。

`p`（表达式求值）和 `w`（watchpoint）由成员 B 负责，你只需要预留接口位置，联调时接入。

## 第四步：实现 SDB 命令循环

这是本阶段最核心的部分。

**骨架结构**（在 `score/src/monitor/sdb.cpp` 中实现）：

```
// 1. 定义命令表结构体
//    每条记录包含：命令名、命令描述、处理函数指针

// 2. 实现各命令处理函数
//    cmd_si(args)   → 单步执行 N 条（PA2 前打印占位提示）
//    cmd_info(args) → 查看寄存器（args == "r" 时打印所有寄存器）
//    cmd_x(args)    → 查看内存（从 args 解析出 N 和 ADDR）
//    cmd_help(args) → 遍历命令表，打印每条命令的名字和描述

// 3. 填写命令表（数组）

// 4. 实现主循环 sdb_mainloop()
//    用 readline() 读取输入
//    用 strtok() 分割命令名和参数
//    在命令表里查找命令名，调用处理函数
```

**需要实现的关键点**：

**`cmd_info` 中打印寄存器的格式**：
