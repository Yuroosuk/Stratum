## 实验一：合并代码

### 目标
把两个 feature 分支合并到 `dev`，解决冲突，让代码能编译通过。

### 步骤

**1. 确认双方状态（各自运行）**

```bash
# 确认本地没有未提交的修改
git status

# 确认 feature 分支已 push
git log --oneline origin/feat/pa1-score-skeleton   # 成员 A 运行
git log --oneline origin/feat/pa1-expr-parser       # 成员 B 运行
```

**2. 由成员 A 执行合并（或两人一起操作）**

```bash
git checkout dev
git pull origin dev

# 先合入 A 的分支
git merge --no-ff feat/pa1-score-skeleton -m "merge: pa1-a SDB skeleton"

# 再合入 B 的分支
git merge --no-ff feat/pa1-expr-parser -m "merge: pa1-b expression parser"
```

**3. 处理冲突（如果有）**

合并可能出现冲突，冲突文件中会有以下标记：

```
<<<<<<< HEAD
// 当前分支的代码
=======
// 要合入分支的代码
>>>>>>> feat/pa1-expr-parser
```

处理原则：
- `sdb.cpp`：主循环结构以 A 的为主
- `expr.cpp`、`watchpoint.cpp`：完全以 B 的为准
- 头文件冲突：手动合并，确保没有重复定义

解决完冲突后：
```bash
git add .
git commit -m "merge: resolve conflicts in PA1 integration"
```

## 实验二：接入 B 的模块到 A 的命令表

### 目标
在 `sdb.cpp` 中加入 `p`、`w`、`d` 命令，并扩展 `info` 命令支持 `info w`。

### 步骤

**1. 在 `sdb.cpp` 中添加 include**

在文件顶部取消之前预留的注释，加入：

```cpp
#include "expr.h"
#include "watchpoint.h"
```

**2. 实现三个新命令处理函数**

在现有命令函数之后添加：

- **`cmd_p(args)`**：
  - 如果 `args` 为空或 NULL，打印 `"Usage: p EXPR"`
  - 调用 `expr_eval(args, &ok)`
  - 如果 `ok`，同时打印十六进制和十进制：`"= 0x%08x  (%u)"`

- **`cmd_w(args)`**：
  - 如果 `args` 为空，打印用法
  - 调用 `wp_add(args)`

- **`cmd_d(args)`**：
  - 如果 `args` 为空，打印用法
  - `atoi(args)` 解析编号，调用 `wp_delete(id)`
  - 根据返回值打印"删除成功"或"找不到该编号"

**3. 扩展 `cmd_info`，支持 `info w`**

在原来判断 `"r"` 的基础上，加一个分支：如果 `args` 是 `"w"`，调用 `wp_print_all()`。

**4. 更新命令表**

在 `cmd_table` 数组中追加三条新命令：

```cpp
{"p",    "p EXPR        对表达式求值并打印",        cmd_p},
{"w",    "w EXPR        设置 watchpoint",           cmd_w},
{"d",    "d N           删除编号为 N 的 watchpoint", cmd_d},
```

同时把 `info` 命令的描述更新为：`"info r/w      查看寄存器或 watchpoint 列表"`

**5. 删除 B 的临时测试文件**

```bash
git rm score/src/monitor/test_expr.cpp
```

**6. 编译**

```bash
make clean && make
```

## 实验三：联调测试

### 目标
两人一起逐条测试，一人操作，一人对照期望结果核对。

### 测试用例

**基础命令（确保 A 的代码没有被 merge 破坏）：**

| 命令 | 期望结果 |
|------|---------|
| `help` | 列出 8 条命令，包含 p/w/d |
| `info r` | 打印 PC + 32 个寄存器，格式整齐 |
| `x 4 0x0` | 打印 4 个 `0x00000000` |
| `si 3` | 打印单步占位提示 |
| `q` | 正常退出，打印 Bye. |

**表达式求值（确保 B 的 expr 正确接入）：**

| 命令 | 期望结果 |
|------|---------|
| `p 1+2` | `= 0x00000003  (3)` |
| `p 2*(3+4)` | `= 0x0000000e  (14)` |
| `p 0xff` | `= 0x000000ff  (255)` |
| `p 1==1` | `= 0x00000001  (1)` |
| `p 1&&0` | `= 0x00000000  (0)` |
| `p $zero` | `= 0x00000000  (0)` |
| `p $pc` | `= 0x00000000  (0)` |
| `p 1/0` | 打印除零错误，不崩溃 |
| `p $xyz` | 打印未知寄存器错误，不崩溃 |

**Watchpoint：**

| 命令 | 期望结果 |
|------|---------|
| `w $pc` | `Watchpoint 1: $pc` |
| `w 1+2` | `Watchpoint 2: 1+2` |
| `info w` | 列出 2 个 watchpoint，显示 last_val |
| `d 1` | 删除成功 |
| `info w` | 只剩 Watchpoint 2 |
| `d 99` | 打印"找不到编号 99"，不崩溃 |

**异常输入（鲁棒性）：**

| 命令 | 期望结果 |
|------|---------|
| `p`（无参数） | 打印 Usage 提示 |
| `w`（无参数） | 打印 Usage 提示 |
| `d`（无参数） | 打印 Usage 提示 |
| `xyz123` | 打印 Unknown command |
